# 🔐 Gerador de Senhas em Java

Gerador de senhas aleatórias desenvolvido em **Java** utilizando **Swing** para criação da interface gráfica.

O projeto permite gerar senhas personalizadas de acordo com o tamanho e os tipos de caracteres escolhidos pelo usuário.

## 🚀 Funcionalidades

- 🔢 Escolher o tamanho da senha
- 🔠 Utilizar letras maiúsculas
- 🔡 Utilizar letras minúsculas
- 🔢 Utilizar números
- 🔣 Utilizar símbolos
- 🎲 Gerar senhas aleatórias
- 📋 Copiar a senha gerada
- 🖥️ Interface gráfica utilizando Java Swing

## 🛠️ Tecnologias utilizadas

- **Java**
- **Java Swing**
- **SecureRandom**

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/gerador-de-senhas-java.git
```

### 2. Entre na pasta

```bash
cd gerador-de-senhas-java
```

### 3. Compile o programa

```bash
javac Main.java
```

### 4. Execute

```bash
java Main
```

Este projeto foi desenvolvido com o objetivo de praticar conceitos de **Java**, **programação orientada a objetos**, **interfaces gráficas**, **geração de números aleatórios** e **manipulação da área de transferência**.
